# Mega-Man-9-MiSTer-FPGA-port
A faithful port of Mega Man 9 to the MiSTer FPGA platform with added features. 
Mega Man is owned by Capcom, I own nothing. 
This project is fully LLM/AI coded, with about 90 hours of human QA so far, and this page will be updated with a proper github release with source code once it is organized and cleaned up for any potential human review or reuse. Issues/bug reports from current fully compiled versions released elsewhere will be attended to here for now.
